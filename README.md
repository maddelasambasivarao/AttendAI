# AttendAI - AI Student Risk Predictor

AI project to predict student failure risk using Attendance, Internals & CGPA.

Tech: Python, Flask, Random Forest (Scikit-Learn)

How to Run:
pip install -r requirements.txt
py app.py

Demo:
- 95% Attendance = LOW RISK - SAFE
- 45% Attendance = HIGH RISK - Counselling Required
